# Kerbal Life-Support System

Because your Kerbals needs Snacks!

![KLSS parts](https://i.imgur.com/SFmissa.png)

## Installation

1. Install [Community Resources](https://spacedock.info/mod/4638/Community%20Resources%20%5BFor%20Redux%2026w39b%5D).
2. Drop the mod into the game's `mods` folder, it should look like `<KSP2 Root>\mods\KerbalLifeSupportSystem\`.
3. When creating a new campaign or when loading an existing one, enabled Kerbal Life-Support System.
